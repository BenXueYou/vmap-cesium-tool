# 08 — 收口编辑会话生命周期与选择联动

**What to build:** 让所有图形在统一编辑链路下遵循同一套会话规则、退出规则和选择联动规则，避免不同入口和不同图形之间的编辑生命周期分叉。

**Blocked by:** 01 — 统一编辑入口与公开编辑契约; 03 — 统一矩形与圆形编辑并恢复 0.x 默认句柄外观; 05 — 恢复多边形删点与合法性约束; 06 — 恢复折线已落点插入与删点编辑

**Status:** ready-for-agent

- [ ] 点击空白地图不退出编辑，双击退出编辑，显式停止接口继续可用。
- [ ] 编辑 A 时切换到 B 会自动提交 A 的最终状态并进入 B 的编辑态。
- [ ] 编辑期间 edit target 强制 selected，普通 hover / pointer selection 暂停，编辑结束后恢复。
