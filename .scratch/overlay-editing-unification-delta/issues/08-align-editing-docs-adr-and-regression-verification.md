# 08 — 收口编辑文档、ADR 与回归验证

**What to build:** 让公开文档、兼容说明、架构记录和高层行为验证与最终落地的统一编辑行为完全一致。用户和维护者读到的默认句柄、回调语义、选择联动和入口职责，必须与真实实现一致，并有回归验证兜底。

**Blocked by:** 03 — 对齐点位默认句柄语义到所有入口; 04 — 对齐矩形与圆形编辑到统一的 0.x 行为; 06 — 拦截非法多边形自相交并给出轻量提示; 07 — 恢复折线旋转与缩放为统一可配置能力

**Status:** ready-for-agent

- [ ] API 文档、编辑指南和兼容入口说明与最终默认交互、实时 `change` / 最终 `end` 语义、选择联动和句柄能力一致。
- [ ] 新增 ADR，明确 `OverlayService` 是唯一编辑内核，`MarkService` 保留标绘编排职责而不再维护重复编辑实现。
- [ ] 回归验证覆盖 `point / rectangle / circle / polygon / polyline` 的关键编辑结果，并证明 `OverlayService`、`MarkService` 与兼容入口在结果上保持一致。
