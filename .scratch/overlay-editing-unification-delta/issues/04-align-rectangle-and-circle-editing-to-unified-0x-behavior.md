# 04 — 对齐矩形与圆形编辑到统一的 0.x 行为

**What to build:** 让矩形和圆形在所有入口上都沿用统一编辑引擎，并把默认句柄外观和图形语义稳定对齐到 0.x。矩形继续是角点编辑，圆形继续是中心点与半径点编辑，不因入口不同而出现默认句柄或回调行为差异。

**Blocked by:** 01 — 统一标绘编辑到单一 Overlay 编辑内核; 02 — 收口 Overlay 编辑句柄配置契约

**Status:** ready-for-agent

- [ ] `rectangle` 在所有入口上保持角点编辑语义，并使用统一的编辑会话和回调模型。
- [ ] `circle` 在所有入口上保持中心点/半径点编辑语义，并使用统一的编辑会话和回调模型。
- [ ] `rectangle` 与 `circle` 的默认句柄外观在所有入口上对齐 0.x。
