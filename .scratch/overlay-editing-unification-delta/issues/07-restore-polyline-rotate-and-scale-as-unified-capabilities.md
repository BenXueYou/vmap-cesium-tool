# 07 — 恢复折线旋转与缩放为统一可配置能力

**What to build:** 让折线的旋转和缩放能力继续存在于统一编辑内核中。默认编辑体验仍以顶点点和边中点为主，不显示额外句柄；当业务显式开启旋转或缩放时，这两种能力能在所有入口上工作且不破坏常规插点与删点体验。

**Blocked by:** 01 — 统一标绘编辑到单一 Overlay 编辑内核; 02 — 收口 Overlay 编辑句柄配置契约

**Status:** ready-for-agent

- [ ] `rotate` 与 `scale` 继续作为统一编辑内核的公开能力存在，而不是只停留在类型和文档层。
- [ ] 折线默认编辑体验不显示旋转和缩放句柄。
- [ ] 当业务显式开启旋转或缩放时，折线在所有入口上都能完成对应操作，且不破坏已落点插入、删点和实时 `change`。
